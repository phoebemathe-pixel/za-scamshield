# 🛡️ ZA-ScamShield

Protecting South Africans from scam SMS with AI ✨

**Accuracy: 75% on 22 local SA SMS**

## What it does
Detects Capitec, SARS, eWallet, Telkom scams using AI (TF-IDF + Logistic Regression)

## How to run
pip install streamlit scikit-learn pandas
streamlit run app.py
python scam_detector.py
